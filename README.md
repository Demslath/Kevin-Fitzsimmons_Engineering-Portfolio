# Kevin Fitzsimmons — Engineering Portfolio

Bioresource engineer (McGill, 2025). Water systems, waste valorization and the hardware in between.

A static site for GitHub Pages: plain HTML, one stylesheet, two small scripts. No build step is needed to publish.

## Structure

| File | What it is |
| --- | --- |
| `index.html` | Splash and home page |
| `capstone.html` | Case study: *Digestate to Clean Water* |
| `experience.html` | Research, kitchen years, coursework, tools and credentials |
| `printing.html` | Workshop: 3D-printed projects and the tape dispenser order page |
| `contact.html` | About, off the clock, what I'm looking for, contact |
| `*-photos.html` | Photo galleries |
| `style.css` | All styles |
| `cover.js` | The generative background, drawn after the Capstone 2 report cover |
| `gallery.js` | Click-to-enlarge photo viewer |
| `images/web/`, `images/thumb/` | Web-sized copies of the photos the site uses |
| `fonts/` | Computer Modern Serif and Inter Tight, self-hosted (SIL Open Font License) |

The original full-resolution photos in `images/` are no longer loaded by the site. They can stay as an archive or be removed to shrink the repo.

To add a photo, export it at about 1800 px on the long edge to `images/web/` and about 760 px to `images/thumb/`, using the same file name in both.
